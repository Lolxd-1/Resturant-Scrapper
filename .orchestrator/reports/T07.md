# T07: Imaging + vision verifier — report

## Implemented

- `studio/imaging.py`: `THUMB_SUFFIX`, `sha256`, `fetch_thumb`, `fetch_full`, `validate_photo`.
  All network/decode failures are swallowed and return `None` (never raise); `fetch_full`
  composites P/RGBA/LA onto white before converting to RGB, downscales with LANCZOS to
  `max_side`, then rejects if the (possibly downscaled) min side is below `min_side`, and
  saves JPEG quality 88 optimize=True.
- `studio/vision.py`: `MODEL_IMAGE`/`MODEL_TEXT` constants, `Vision` Protocol, `ClipVision`
  (lazy-loads fastembed `ImageEmbedding`/`TextEmbedding` under a lock, caches text
  embeddings by string, `available` flips True only once both models load), `NullVision`
  (raises `RuntimeError("vision unavailable")` from both embed methods), `load_vision`
  (try/except around construction + a 1-image/1-text smoke embed → `NullVision` on any
  exception), `FOOD_PROMPTS`/`NONFOOD_PROMPTS`, `food_ok` (softmax over 100×cosine, food
  probability ≥ 0.5), `head_ok` (one prompt per `HEAD_GROUP` group from a stable
  first-head representative, plus the given head's own prompt; veto only when another
  group's best prompt beats the head's own by more than 0.02), `consensus` (weighted
  mean cosine to all other vectors, min-max scaled to 0..1, ties → 0.5, n≤1 → ones),
  `text_sim` (cosine to `"a photo of {text}"`, mapped `(cos-0.15)/0.2` clipped to 0..1).

  garbage bytes→None, undersized bytes→None), TC2 (full: 2000×1500 RGBA PNG →
  1600×1200 JPEG bytes; 300×300→None below `min_side`; 1000×200 banner→None "odd
  shape"; solid-grey 800×800→None "blank"; 404/missing→None), TC7 (`sha256(b"abc")`
  against the known digest).
- `tests/test_vision.py`: `FakeVision` (deterministic one-hot embeddings keyed by
  string/first-byte, per brief step 10) covering TC3 (`NullVision` raises/unavailable;
  `load_vision` falls back to `NullVision` when `ClipVision` construction is
  monkeypatched to raise), TC4 (food_ok: logo→False, food-on-a-plate→True), TC5
  (head_ok: image aligned to the pizza prompt → `DAL` False / `PIZZA` True / `None`
  True — **substituted `DAL` for the brief's `CURRY`**, since T06 removed `CURRY` as a
  head; `DAL` is in a different `HEAD_GROUP` ("curry") than `PIZZA`, preserving the
  test's intent), TC6 (consensus: 3 identical + 1 orthogonal → orthogonal scores 0.0,
  others ≥ 0.9), plus one extra test for `text_sim` and one for `consensus` n=1. TC8
  (`test_tc8_real_clip_smoke`) is present and gated by
  `@pytest.mark.skipif(not _real_vision_ready(), ...)` (env `MENUSTUDIO_TEST_REAL_VISION=1`
  or a non-empty `config.models_dir()`); it is skipped in the default verify run.
