## Steps
1. `fold_homoglyphs`: map Cyrillic and Greek letters that look Latin to Latin (upper and lower: А→A В→B Е→E К→K М→M Н→H О→O Р→P С→C Т→T Х→X У→Y а→a е→e о→o р→p с→c у→y х→x і→i ј→j ѕ→s ԁ→d, Greek Α Β Ε Ζ Η Ι Κ Μ Ν Ο Ρ Τ Υ Χ and ο ν). "PANEER CHАТРАТА" -> "PANEER CHATPATA".
2. `transliterate`: if the text contains Devanagari (U+0900–U+097F): first replace whole words found in DEVANAGARI_WORDS (at least: चिकन chicken, मटन/मटण mutton, हंडी/हांडी handi, थाळी/थाली thali, मालवाणी malvani, ड्राय dry, स्पेशल special, स्पे. special, हाफ half, फुल full, प्लेट plate, कंदुरी kanduri, राजाराणी rajarani, व्हेज veg, मांसाहारी nonveg, शाकाहारी veg, पनीर paneer, भाजी bhaji, वडा vada, पाव pav, मिसळ misal, पोहे poha, भात bhat, चपाती chapati, भाकरी bhakri, अंडा/अंडी anda, बिर्याणी/बिर्यानी biryani, रस्सा rassa, सुका/सुकं sukka, तांबडा tambda, पांढरा pandhra, फ्राय fry, मसाला masala, कोल्हापुरी kolhapuri, डाळ/दाल dal, पिठलं/पिठले pithla, शेव shev, लस्सी lassi, ताक taak, दही dahi, वरण varan, आमटी amti, कोंबडी kombdi, मच्छी machhi, सोलकढी solkadhi, भरीत bharit, झुणका zunka, उसळ usal, थाळी thali, राडा rada), then transliterate remaining Devanagari with simple rules (consonants with inherent "a", vowel signs, virama removes the vowel, anusvara -> "n", nukta ignored, drop the final inherent "a" of a word, punctuation like "." kept). Latin text passes through unchanged.
3. `normalize()` in text.py calls fold_homoglyphs then transliterate before its existing steps. `parse_dish(..., *, display=None)`: DishQuery.display = display if given else the cleaned original name (so the sheet keeps what the vendor wrote).
4. MISSPELLINGS (curated, applied first; lowercase): bater→butter, battar→butter, jira→jeera, jeera stays, stim→steam, sezvan→schezwan, shezwan→schezwan, schzwan→schezwan, mashrum→mushroom, mashroom→mushroom, mushrum→mushroom, soyabin→soyabean, soyabeen→soyabean, kari→curry, karri→curry, tanduri→tandoori, haidrabadi→hyderabadi, hydrabadi→hyderabadi, chatani→chutney, chatni→chutney, pital→pitla, pithal→pitla, crispi→crispy, crespi→crispy, cranchi→crunchy, cranchy→crunchy, pis→peas, garlik→garlic, kulchchha→kulcha, kulchha→kulcha, lachchha→lachha, lacha→lachha, ghi→ghee, plet→plate, haf→half, ful→full, leman→lemon, lemon stays, coriunder→coriander, coriandar→coriander, khima→keema, kheema stays, kophta→kofta, jayka→zaika, jaika→zaika, lajvab→lajawab, lajawaab→lajawab, mataki→matki, masur→masoor, rost→roast, panner→paneer, panir→paneer, checken→chicken, chiken→chicken, chikan→chicken, matan→mutton, muttan→mutton, akhkha→akkha, boil→boiled, nan→naan, tava stays (lexicon has tawa/tava), vit→wheat (Marathi "vit"/"ghavhachi"), harbhara→hara bhara, harabhara→hara bhara, manjara→majestic? (NO: leave manjara unchanged), mith→meeth? (NO: leave unchanged), aalni→aalni (leave).
   Lexicon (true synonyms, add to SYNONYMS/PHRASES): kari/karri -> the same soft CURRY token as curry/rassa; "boiled egg"/"boil anda"/"boiled anda" -> BOILEDEGG; "anda" already EGG; "hara bhara" phrase stays; "steam rice"/"steamed rice"/"plain rice"/"sada rice"/"white rice" -> same tokens (steam is soft STEAM, plain handled); "wheat roti"/"chapati" NOT merged (different look is small but keep separate).
5. `phonetic_key(word)`: lowercase; replace in order "chh"->"c","ch"->"c","ph"->"f","sh"->"s","kh"->"k","gh"->"g","th"->"t","dh"->"d","bh"->"b","jh"->"j","ck"->"k","q"->"k","x"->"ks","w"->"v","z"->"j","ee"->"i","oo"->"u"; then keep the first letter and drop every other vowel (a e i o u y); collapse repeated letters. Examples: mashrum -> "msrm" == mushroom; bater -> "btr" == butter; kulchchha -> "klc" == kulcha.
6. `Speller(vocab)` where vocab = PoolIndex.word_counts() (lowercase raw words of item names, df). `correct(word)`: (a) lowercase; len < 3 or has digits -> None; (b) MISSPELLINGS hit -> replacement; (c) word in vocab with df >= 2, or a key of SYNONYMS/PHRASES/NOISE/NON_VISUAL, -> None (known: never change); (d) glued words: split into 2-3 parts (each len >= 3) where every part is known (df >= 5) or a MISSPELLINGS key; choose the split with the fewest parts and highest min df; return parts joined by spaces with MISSPELLINGS applied ("andakari" -> "anda curry", "boilanda" -> "boiled anda", "greenpis" -> "green peas"); (e) phonetic: candidates = vocab words with df >= 5, same phonetic_key, same first letter group (c/k/q, s, j/z, v/w, others exact), and rapidfuzz Levenshtein distance <= 2 (<= 1 when len(word) <= 5); pick the highest df; if the second best has df >= 0.5 * best df and is a different word -> ambiguous -> None; else return the best. `fix_text(text)`: normalize the text (text.normalize keeps words), correct each word, rejoin.
7. matcher.py: `PoolIndex.word_counts()` built lazily once (cache) from `normalize(item.name).split()` per item (document frequency).
8. pipeline.py: when building each row's DishQuery, compute `speller = Speller(engine.index.word_counts())` once per job (log "Spelling helper ready: N words"); `fixed = speller.fix_text(row.name)`; `q = parse_dish(fixed, row.category, row.description, display=row.name)`. Also pass the category through `speller.fix_text` for diet/head hints but keep the ORIGINAL category string for the sheet. Log each change once per job as "Read 'BATER NAN' as 'butter naan'" (cap 200 log lines). Diet hints: add "shakahari"/"shaakahari" -> veg and "mansahari"/"maansahari"/"nonveg" -> nonveg to the lexicon diet hints (Devanagari versions arrive transliterated via DEVANAGARI_WORDS).
