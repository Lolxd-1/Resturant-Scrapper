# T07: Imaging (download/validate) + vision verifier (CLIP via fastembed)
Wave: 7 · Deps: T03, T04, T05 · Risk: med · Model: sonnet

## Goal
`studio/imaging.py` downloads Zomato photos (small thumbnails for screening, full size for the final pick) and validates them; `studio/vision.py` wraps a local CLIP model (fastembed, ONNX, CPU) and provides four verifier signals — food check, dish-group check, image consensus, text-image similarity — with a graceful `NullVision` fallback when the model is unavailable.

## Context
Measured by the orchestrator (findings.md "Vision"): CLIP ViT-B/32 is weak at fine-grained dish names (top1 0.27) but useful for coarse groups (0.72) and image-image agreement. So vision only VETOES clear mismatches and breaks ties. fastembed's default cache is %TEMP% (can be wiped): always pass `cache_dir`.

## Contracts
- imaging.py: `THUMB_SUFFIX = "?fit=around%7C300%3A300&crop=300%3A300%3B%2A%2C%2A"`, `fetch_thumb(url: str, http: Http) -> bytes | None`, `fetch_full(url: str, http: Http, min_side: int = 400, max_side: int = 1600) -> tuple[bytes, tuple[int, int]] | None`, `validate_photo(img: PIL.Image.Image) -> str | None` (None = OK, else a short reason), `sha256(data: bytes) -> str`.
- vision.py: `MODEL_IMAGE = "Qdrant/clip-ViT-B-32-vision"`, `MODEL_TEXT = "Qdrant/clip-ViT-B-32-text"`, `class Vision(Protocol)` (attributes `available: bool`, `reason: str`; methods `embed_images(self, images: list[bytes]) -> np.ndarray`, `embed_texts(self, texts: list[str]) -> np.ndarray`, both returning L2-normalized float32 arrays of shape (n, d)), `class ClipVision`, `class NullVision`, `load_vision(cache_dir: Path, allow_download: bool = True) -> Vision`, `food_ok(vision, img_vecs) -> np.ndarray` (bool), `head_ok(vision, img_vecs, head: str | None) -> np.ndarray` (bool), `consensus(img_vecs, weights) -> np.ndarray` (float 0..1), `text_sim(vision, img_vecs, text: str) -> np.ndarray` (float 0..1).

## Steps
1. imaging.fetch_thumb: `http.get(url.split("?")[0] + THUMB_SUFFIX)`; return content if status 200 and len >= 1500 bytes and it decodes with PIL; else None. Never raise.
2. imaging.fetch_full: GET the url without query; PIL open + load inside try; `validate_photo` must return None; convert to RGB (handle P/RGBA/LA by pasting on white), downscale so max side <= max_side (LANCZOS), reject if min side < min_side; save JPEG quality 88, optimize=True, no EXIF; return (bytes, (w, h)). Never raise; return None on any failure.
3. validate_photo: reason strings: "too small" (min side < 200), "odd shape" (aspect ratio > 2.2 or < 0.45), "blank" (grayscale stddev < 8 on a 64x64 thumbnail), else None.
4. ClipVision(cache_dir): lazily construct `fastembed.ImageEmbedding(MODEL_IMAGE, cache_dir=str(cache_dir))` and `TextEmbedding(MODEL_TEXT, cache_dir=str(cache_dir))` under a lock on first use (or in `load()`); `embed_images` decodes bytes to PIL RGB and calls `embed(list_of_images, batch_size=32)`; normalize rows; text embeddings cached in a dict by string. `available` True only after both models loaded.
5. load_vision(cache_dir, allow_download): try to build ClipVision and run a 1-image + 1-text smoke embedding; when `allow_download` is False pass `local_files_only=True` if the installed fastembed supports it. Any exception -> `NullVision(reason=<short message>)` and log a warning. NullVision: available False, embed_* raise RuntimeError("vision unavailable").
6. Prompts: FOOD_PROMPTS = ["a photo of food on a plate", "a photo of a dish of Indian food", "a photo of a drink in a glass", "a photo of a dessert", "a close-up photo of a meal"]; NONFOOD_PROMPTS = ["a logo", "a poster with text", "a menu card with prices", "a photo of a person", "a restaurant interior", "an empty table", "a cardboard delivery box with a brand logo", "a collage of many different dishes"]. food_ok: softmax over (100 * cosine) of all prompts; food probability = sum over FOOD; True when >= 0.5.
7. head_ok(vision, vecs, head): if head is None or head not in HEAD_PROMPT -> all True. Build one prompt per HEAD_GROUP group using the HEAD_PROMPT of a representative head (first head in each group, stable order) plus the specific head's own prompt for its group; compute cosine to every group prompt; own = similarity to the dish head's prompt; best_other = max similarity among prompts of OTHER groups; return `own >= best_other - 0.02` (a veto only when another group clearly wins).
8. consensus(vecs, weights): for n <= 1 return ones; else for each i: weighted mean cosine to all j != i (weights >= 0, normalized), then min-max scale to 0..1 across the n (all equal -> 0.5).
9. text_sim(vision, vecs, text): cosine to `f"a photo of {text}"` embedding, mapped 0..1 via `(cos - 0.15) / 0.2` clipped.
10. Tests use a `FakeVision` defined in the test file: deterministic embeddings (e.g. images are bytes whose first byte selects a basis direction; texts map by keyword to directions) so food_ok/head_ok/consensus logic is tested without the model. One test `test_real_clip_smoke` is skipped unless the model is already present in `MENUSTUDIO_HOME/models` or env `MENUSTUDIO_TEST_REAL_VISION=1`; when it runs, it loads ClipVision from `config.models_dir()`, embeds `smartbiz_out_hfood/zimages/HFC-004.jpg` (a pizza) and asserts head_ok for "PIZZA" True and for "SHAKE" False.

## Test cases
- TC1 fetch_thumb appends the suffix to a url with an existing query string removed; 404 -> None; garbage bytes -> None.
- TC2 fetch_full: a 2000x1500 PNG with alpha -> JPEG bytes with size (1600, 1200); a 300x300 image -> None; a 1000x200 banner -> None ("odd shape"); a solid-colour 800x800 -> None ("blank").
- TC3 NullVision.available False and load_vision returns NullVision when construction raises (monkeypatch ClipVision to raise).
- TC4 food_ok with FakeVision: a vector aligned to "a logo" -> False; aligned to "food on a plate" -> True.
- TC5 head_ok with FakeVision: image aligned with the pizza prompt, head "CURRY" -> False; head "PIZZA" -> True; head None -> True.
- TC6 consensus: three near-identical vectors + one orthogonal -> the orthogonal one has the lowest score (0.0) and the others >= 0.9.
- TC7 sha256 of b"abc" equals the known hex digest.
- TC8 test_real_clip_smoke (conditional, see step 10).
