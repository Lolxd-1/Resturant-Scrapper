# A4: Look-alike names + "review" status in models and sheets
Wave: 2 · Deps: A2 · Risk: med · Model: sonnet

## Goal
(1) `text.lookalike_names(name)` returns up to two more generic dish names whose photo looks like the dish. (2) Shared models gain the review status and look-alike fields. (3) Sheets/report understand the "review" status.

## Context
Dishes with no exact photo will get a photo of a look-alike name ("Green Chilli Paneer Pizza (Single Cheese)" -> "Green Chilli Paneer Pizza" -> "Paneer Pizza"). Such dishes get status "review" and wait for the user's approval (task A5/A6). Review rows must land in the PENDING SmartBiz sheet, never in UPLOAD_READY, until approved.

## Contracts (produce exactly)
```text
models.py: STATUSES = ("ready", "review", "needs_photo", "needs_price", "error")
           SOURCES  = ("own", "chain", "pool", "live", "swiggy", "")

```

## Steps
1. models.py: the constants and fields above, with short trailing comments like the file's existing ones.
2. text.py `lookalike_names(name)` (public, near `size_base_key`), docstring one line. Algorithm:
   a. `main = " ".join(_PAREN_RE.sub(" ", name).split())`; if `main` and `size_base_key(main) != size_base_key(name)` -> first name `main`.
   b. Core name: `toks = _tokens(main, fallback=False)`; if no token in `HEADS` -> stop. `keep = [t for t in toks if t in HEADS or token_role(t) in ("base", "protein")]`; if `keep == toks` -> stop. Render each kept token with a module dict `_DISPLAY` for multi-word canonical tokens (FRIEDRICE "fried rice", PAVBHAJI "pav bhaji", VADAPAV "vada pav", COLDCOFFEE "cold coffee", ICECREAM "ice cream", GARLICBREAD "garlic bread", SPRINGROLL "spring roll", MASALAPAPAD "masala papad", MASALADOSA "masala dosa", SABUDANAKHICHDI "sabudana khichdi", DALKHICHDI "dal khichdi", BOILEDEGG "boiled egg", BUNMASKA "bun maska", PERIPERI "peri peri", ICEDTEA "iced tea", MIXVEG "mix veg"), else `t.lower()`. If no protein token is kept and `" veg "` is in `f" {normalize(name)} "` and neither "non veg" nor "nonveg" is, prefix "veg". Title-case the words (`str.title()` per word). Add it if its size_base_key differs from the name's and from the first name's.
   c. Return the list (0, 1 or 2 names).
3. sheets.py: `STATUS_LABELS["review"] = "Review look-alike"`; summary gets a row `("Look-alikes to review", review_n)` right after "Ready to upload"; append a column "Photo searched as" (value `r.search_name`, width 22) at the END of DISHES_HEADER/DISHES_WIDTHS/_write_dishes rows. Nothing else changes (review rows already go to PENDING because status != "ready").
