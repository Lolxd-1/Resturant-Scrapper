## Steps
1. `Http`:
   - session defaults to a new `requests.Session()`; set headers `User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/128.0.0.0 Safari/537.36`, `Accept-Language: en-US,en;q=0.9`, `Accept: text/html,application/json;q=0.9,*/*;q=0.8`.
   - Throttle per host: a `threading.Lock` + dict host->last request time; before a request to host `www.zomato.com` wait until `min_interval` seconds since the previous one (use injected `sleep`/`clock`). CDN hosts (`b.zmtcdn.com`) use `min_interval/4`. Thread-safe.
   - Retry loop (attempts = max_retries + 1): exceptions from requests (ConnectionError, Timeout, ChunkedEncodingError) and status 429/500/502/503/504 -> sleep `min(30, 2 ** attempt) + 0.1*attempt` or the integer `Retry-After` header when present (capped 60), then retry. 404/410 -> return None immediately. 200 -> return the response. 403 or a 200 whose text contains "captcha" (case-insensitive) AND lacks "__PRELOADED_STATE__" AND the url is a zomato.com HTML page -> count as blocked: retry with backoff; after the last attempt raise `ZomatoBlocked(url)`. Other statuses -> return None. After exhausting retries on network errors/5xx -> return None and log a warning with the url.
2. `parse_state(html)`: regex `__PRELOADED_STATE__\s*=\s*JSON\.parse\(("(?:[^"\\]|\\.)*")\)` with re.S; `json.loads(json.loads(group1))`; any failure -> None.
3. `canonical_res_url(url)`: accept absolute or relative (`/pune/x`), strip query/fragment, strip trailing `/order`, `/info`, `/menu`, `/reviews`, `/photos` and trailing slashes, force `https://www.zomato.com` prefix, lowercase path. `city_of(url)` = first path segment. `chain_key(name)`: lowercase, drop apostrophes, non-alnum -> space, collapse, strip (e.g. "La Pino'z Pizza" -> "la pinoz pizza").
4. `parse_menu(state, fallback_url)`: resId = state["pages"]["current"]["resId"] (str); R = state["pages"]["restaurant"][resId]; info = R["sections"]["SECTION_BASIC_INFO"]; name = info["name"]; url = canonical_res_url(info.get("resUrl") or fallback_url); if info.get("is_perm_closed") is True -> return RestaurantMenu with items [] (still valid). Walk R["order"]["menuList"]["menus"][*]["menu"] (menu_name = menu["name"]) -> ["categories"][*]["category"] (category = category["name"]) -> ["items"][*]["item"]. For each item: image = item["item_image_url"], else the first media[*].image.url; skip items without an http(s) image; strip the query string from the image url. diet = map dietary_slugs: "veg"->"veg", "non-veg"->"nonveg", "egg"->"egg", else "unknown". description = item.get("desc") or "" with whitespace collapsed, cut to 300 chars. Build PoolItem(item_id=0, name=item name stripped, category, menu_name, description, diet, img_url, res_id=resId, res_name=name, res_url=url, city=city_of(url), chain_key=chain_key(name)). Deduplicate identical (name, img_url) within one restaurant. Any KeyError/TypeError on the top-level path -> return None (log debug).
5. `ZomatoClient.fetch_menu(res_url)`: GET `canonical_res_url(res_url) + "/order"`; None response -> None; parse_state -> parse_menu(state, fallback_url=canonical url); log `info` "menu <slug>: N imaged items".
6. `suggest(query, city)`: GET `https://www.zomato.com/webroutes/search/autoSuggest` with params `{"addressId": 0, "entityId": CITIES[city], "entityType": "city", "q": query, "context": "delivery"}` (unknown city -> return empty SuggestResult). Parse JSON `results`: entityType "restaurant" -> (info.name or name, canonical_res_url(actionInfo.clickUrl)); "chain_outlets" -> chains.append(absolute url of actionInfo.clickUrl); "universal_dish" -> dishes.append((entityId, name)). Malformed JSON -> empty result.
7. `listing(city, cuisine)`: GET `https://www.zomato.com/{city}/restaurants/{cuisine}`; regex `/{city}/([a-z0-9\-]{4,})/(?:info|order)` on the HTML text; unique in order; return canonical urls. None response -> [].
8. `chain_outlets(chain_url)`: GET the chain url (absolute; relative -> prefix https://www.zomato.com); state = parse_state; walk every value of state["pages"]["search"] that is a dict -> ["sections"]["SECTION_SEARCH_RESULT"] list -> entry.get("cardAction", {}).get("clickUrl") (skip entries without it) -> canonical urls; if state missing, fall back to the listing regex using the city from the final response url.
9. `dish_restaurants(city, dish_id)`: GET `https://www.zomato.com/{city}/delivery?dishv2_id={dish_id}&category=1`; same SECTION_SEARCH_RESULT walk.
10. `tests/fixtures/zomato/make_pages.py`: helpers that build synthetic HTML from Python dicts exactly like Zomato: `state_html(state: dict) -> str` returns `'<html><script>window.__PRELOADED_STATE__ = JSON.parse(' + json.dumps(json.dumps(state)) + ');</script></html>'`; `menu_state(res_id, name, res_url, menus)` where menus = list of (menu_name, [(category_name, [item dicts])]); `item(name, img, diet="veg", desc="")` producing {"id":..., "name":..., "desc":..., "dietary_slugs":[...], "item_image_url": img}; `search_state(click_urls)`; `suggest_json(entries)`. Include in one item's desc the text `);` and a `"` and `\` so the robust regex is exercised.

## Test cases (tests/test_zomato.py)
- TC1 parse_menu on a synthetic 2-menu/3-category state -> items carry category, menu_name, diet, description; items without image skipped; image query string stripped; description containing `);` parsed intact.
- TC2 parse_state returns None for html without the marker and for truncated JSON.
- TC3 fetch_menu via FakeSession: GET goes to `.../slug/order` for input urls ending in `/info`, `/order`, `/` or with a query string.
- TC4 retry: FakeSession returns 503, 503, 200 -> get returns the 200 response, and injected sleep was called twice; 429 with `Retry-After: 7` -> sleep called with 7.
- TC5 404 -> None with a single call; ConnectionError raised 5 times -> None after 5 calls (max_retries=4).
- TC6 blocked: 403 every time on a zomato.com page -> raises ZomatoBlocked after max_retries+1 calls.
- TC7 suggest parses restaurant / chain_outlets / universal_dish entries (use the exact shapes quoted in findings.md) and ignores unknown types; unknown city -> empty result with no HTTP call.
- TC8 listing extracts unique canonical urls from HTML containing duplicate `/pune/abc-def/info` and `/pune/abc-def/order` links.
- TC9 chain_outlets walks SECTION_SEARCH_RESULT and skips entries without cardAction.
- TC10 throttle: two consecutive gets with min_interval=1.0, fake clock not advancing -> sleep called with ~1.0 before the second call.
- TC11 perm-closed restaurant -> RestaurantMenu with 0 items (not None).
- TC12 (real file, skip if absent): every `zcache/*order.html` in the repo root parses with parse_menu and >= 180 of them yield >= 1 item; the burger_king_1_hadapsar page yields items.
- TC13 chain_key("La Pino'z Pizza") == "la pinoz pizza"; canonical_res_url("/pune/Abc-Def/order?x=1") == "https://www.zomato.com/pune/abc-def"; city_of that == "pune".
