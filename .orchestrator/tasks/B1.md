# B1: Gemini REST client (free tier) + Settings.gemini_key
Wave: 5 · Deps: A5 · Risk: high (API key handling) · Model: sonnet

## Goal
`studio/gemini.py` sends one JSON-answer request to the Gemini API (free tier), surviving quota limits by falling back across free models, throttling, caching answers on disk, and never exposing the key. Settings persist a `gemini_key`.

## Context
User ruling: Google Gemini free tier only. Free limits are tiny (gemini-3.8-flash ~20 requests/day, ~10/min; each model has its own quota; daily reset at midnight US Pacific = about 12:30 PM India time). REST (verified 2026-10-07): `POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent`, header `x-goog-api-key`, body `{"systemInstruction": {"parts": [{"text": ...}]}, "contents": [{"role": "user", "parts": [...]}], "generationConfig": {"responseMimeType": "application/json", "responseJsonSchema": <schema>, "maxOutputTokens": N, "mediaResolution": "MEDIA_RESOLUTION_HIGH"}}`; image part `{"inlineData": {"mimeType": "image/jpeg", "data": <base64>}}`; answer text in `candidates[0].content.parts[*].text` (skip parts with `"thought": true`), `candidates[0].finishReason` "STOP" when complete. Errors: JSON `{"error": {"code", "message", "status", "details": [...]}}`; quota details contain `{"@type": "...QuotaFailure", "violations": [{"quotaId": "...PerDay..."}]}` and `{"@type": "...RetryInfo", "retryDelay": "41s"}`. No new dependencies: use `requests`.

## Contracts (produce exactly)
```text
studio/gemini.py:
  API_BASE = "https://generativelanguage.googleapis.com/v1beta"
  MODELS: tuple[str, ...] = ("gemini-3.8-flash", "gemini-3.7-flash", "gemini-3.6-flash", "gemini-3.5-flash", "gemini-2.5-flash")
  class GeminiError(Exception)              # str(exc) is a plain-English message for the user
  class GeminiQuotaError(GeminiError)       # every model is out of free quota right now
  def text_part(text: str) -> dict          # {"text": text}
  def image_part(data: bytes, mime: str = "image/jpeg") -> dict   # {"inlineData": {"mimeType": mime, "data": base64 str}}
  class Gemini:
      __init__(self, api_key: str, *, cache_dir: Path | None = None, models: tuple[str, ...] = MODELS,
               post=requests.post, get=requests.get, sleep=time.sleep, clock=time.monotonic, min_interval: float = 6.5)
      available: bool          # bool(api_key.strip())
      last_model: str          # model that answered the last call; "cache" for a cache hit
      generate_json(self, system: str, parts: list[dict], schema: dict, *, high_res: bool = False,
                    max_output_tokens: int = 65536) -> dict
      check_key(self) -> tuple[bool, str]   # GET {API_BASE}/models?pageSize=1 with the header; (True, "Gemini key works") / (False, reason)
studio/models.py: Settings + gemini_key: str = ""   (last field)
studio/config.py: load/save gemini_key (strip; non-str -> ""); def ai_cache_dir() -> Path   # home_dir()/"ai_cache", created
```

## Steps
1. Module state shared by all instances (one process, many jobs): `_lock`, `_last_start: float | None`, `_exhausted: dict[str, float]` (model -> clock time until which it is skipped). Throttle: before each HTTP request wait so that starts are >= min_interval apart.
2. `generate_json`: if not available -> GeminiError("Add your free Gemini API key in Settings first."). Cache (when cache_dir): key = sha256 of `json.dumps({"system", "schema", "high_res", "parts": [text parts as-is, image parts replaced by {"image": sha256 of the base64 data}]}, sort_keys=True)`; hit -> return parsed JSON, last_model "cache". Then for each model not exhausted (now < until): POST with timeout 240 s. Outcomes:
   - 200, finishReason STOP, text parses to a dict -> write cache (atomic_write_text), set last_model, log INFO model + usageMetadata token counts, return.
   - 200 but no candidates / finishReason != STOP / not JSON dict -> log WARNING with model + finishReason, next model.
   - 429: quotaId containing "PerDay" -> `_exhausted[model] = now + 3600`, next model. Otherwise sleep min(retryDelay seconds or 20, 60) and retry this model once; a second 429 -> next model.
   - 400 whose message mentions "API key" (or status 401/403) -> raise GeminiError("Your Gemini key was rejected. Check it in Settings.") immediately.
   - 400 otherwise: if high_res, retry this model once without mediaResolution; else raise GeminiError(f"Gemini rejected the request: {message[:200]}").
   - 404 -> next model. 5xx or requests.RequestException -> sleep 5, retry once, then next model.
   After the loop: if every attempted model failed on quota (or all were already exhausted) -> GeminiQuotaError("The free Gemini quota is used up for now on every model. It resets around 12:30 PM India time; you can also use the Gemini website prompt."), else GeminiError("Gemini could not answer right now (<last reason>). Try again in a few minutes.").
3. Never put the key in URLs, logs, exceptions or cache files. Log with `log = logging.getLogger("studio.gemini")`.
4. config.py + models.py: persist gemini_key alongside the other settings; `ai_cache_dir()`.
