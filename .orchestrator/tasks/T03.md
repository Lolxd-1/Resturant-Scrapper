# T03: Lexicon + dish text understanding
Wave: 3 · Deps: T01 · Risk: high · Model: opus

## Goal
`studio/lexicon.py` (data) and `studio/text.py` (functions) turn an Indian restaurant dish name — including Marathi/Hindi regional words, size suffixes, parenthetical aliases and combos — into a precise canonical representation (`DishQuery`), and derive the dish type of any Zomato item using its menu category as context. This is the foundation of photo accuracy: a word that changes how the dish LOOKS must never be dropped, and different dishes must never collapse to the same tokens.

## Context
Read `.orchestrator/recon/findings.md` sections "Root causes" and "Past vendor runs". v1 lexicon lives in `zomato_scrapper.py` lines 136-273 (CANON groups, STOP, NONVEG_WORDS): reuse its correct synonyms but NOT its mistakes (bharwa->BAINGAN, besan->PITLA, kulcha->PARATHA, bhakri->ROTI, vada->PAKODA, chaap->SOYA, and STOP words that drop visual words like peri, dum, tulsi, adrak treated as noise).

## Contracts
- Produces (text.py): `normalize(text: str) -> str`, `tokens(text: str) -> list[str]`, `parse_dish(name: str, category: str = "", description: str = "") -> DishQuery`, `item_head(name: str, category: str = "", menu_name: str = "") -> str | None`, `item_proteins(name: str) -> frozenset[str]`, `size_base_key(name: str) -> str`, `is_combo_name(name: str) -> bool`, `token_role(token: str) -> str` (one of "head","protein","base","visual","soft","nonvisual").
- Produces (lexicon.py): `SYNONYMS: dict[str, str]`, `PHRASES: dict[str, str]`, `NOISE: frozenset[str]`, `NON_VISUAL: frozenset[str]`, `SOFT: frozenset[str]`, `HEADS: dict[str, str]`, `HEAD_GROUP: dict[str, str]`, `HEAD_PROMPT: dict[str, str]`, `HEAD_CUISINES: dict[str, tuple[str, ...]]`, `PROTEINS: dict[str, str]`, `NONVEG_PROTEINS: frozenset[str]`, `COMBO_WORDS: frozenset[str]`, `CATEGORY_HEAD_HINTS: dict[str, str]`, `DIET_HINTS_NONVEG: frozenset[str]`, `DIET_HINTS_VEG: frozenset[str]`.
- Canonical tokens: lowercase for ordinary words (singularized: trailing "s" dropped when len>3 and not "ss", applied before synonym lookup AND after); UPPERCASE for canonical concepts from SYNONYMS/PHRASES/HEADS/PROTEINS (e.g. "PIZZA", "CHICKEN", "GOBI", "BUTTERMILK", "PERIPERI").

## Steps
1. `normalize`: unicodedata NFKD + drop combining marks (Crème->creme), lowercase, `&`->" and ", `+`->" plus ", any char not a-z0-9 -> space, collapse spaces, strip. Non-latin scripts (Devanagari) become empty after folding: `tokens()` on such names returns [] and parse_dish must still return a valid DishQuery (variants=(frozenset(),)).
2. PHRASES (applied on the normalized string, longest first, whole-word): at least: "peri peri"->"PERIPERI", "piri piri"->"PERIPERI", "french fries"->"FRIES", "finger chips"->"FRIES", "cold coffee"->"COLDCOFFEE", "ice cream"->"ICECREAM", "icecream"->"ICECREAM", "garlic bread"->"GARLICBREAD", "pav bhaji"->"PAVBHAJI", "vada pav"->"VADAPAV", "bun maska"->"BUNMASKA", "thick shake"->"SHAKE", "milk shake"->"SHAKE", "milkshake"->"SHAKE", "virgin mojito"->"MOJITO", "masala papad"->"MASALAPAPAD", "sabudana khichdi"->"SABUDANAKHICHDI", "sabudana khichadi"->"SABUDANAKHICHDI", "dal khichdi"->"DALKHICHDI", "spring roll"->"SPRINGROLL", "fried rice"->"FRIEDRICE", "hakka noodles"->"NOODLES", "cheese burst"->"CHEESEBURST", "gulab jamun"->"GULABJAMUN", "rava sheera"->"SHEERA", "suji halwa"->"SHEERA", "egg bhurji"->"EGG BHURJI", "anda bhurji"->"EGG BHURJI", "masala dosa"->"MASALADOSA", "misal pav"->"MISAL", "dahi wati"->"CURD", "dahi vati"->"CURD", "boiled egg"->"BOILEDEGG", "paneer tikka"->"PANEER TIKKA", "soya chunks"->"SOYA", "soyabean chunks"->"SOYA", "chicken dum"->"CHICKEN dum". Add more you are confident are true equivalents.
3. SYNONYMS (exact equivalents only; word -> canonical). Must include at least: murgh/murghi/chicken->CHICKEN; gosht/mutton/lamb->MUTTON; anda/egg/eggs/ande->EGG; machli/machhi/fish->FISH; prawn/prawns/shrimp/kolambi/kolmi->PRAWN; gobi/cauliflower/flower/phool->GOBI; aloo/alu/potato/batata->ALOO; matar/mutter/peas/vatana->MATAR; palak/spinach->PALAK; bhindi/bhendi/okra->BHINDI; baingan/brinjal/eggplant/vangi/vange->BAINGAN; methi/fenugreek->METHI; lasun/lasoon/lehsun/garlic->GARLIC; kanda/pyaz/pyaaz/onion->ONION; tamatar/tomato->TOMATO; mushroom/alambi->MUSHROOM; shevga/drumstick/moringa/shevgyachya->SHEVGA; shev/sev->SEV; kaju/cashew->KAJU; chana/chole/chickpea/kabuli->CHANA; dal/daal/dhal/lentil/amti/varan->DAL; tadka/tarka/phodni->TADKA; jeera/zeera/cumin->JEERA; biryani/biriyani/biriani->BIRYANI; pulao/pulav/pulaav/pilaf->PULAO; rice/bhaat/bhat/chawal->RICE; manchurian/manchuria->MANCHURIAN; chilli/chili/chilly->CHILLI; bhurji/burji->BHURJI; keema/kheema/qeema/kheema->KEEMA (NOT bhurji); kadai/kadhai/karahi->KADAI; pahadi/hariyali->HARIYALI; tandoor/tandoori->TANDOORI; tawa/tava->TAWA; butter/makhan/makkhan->BUTTER; makhani->MAKHANI (distinct from BUTTER); momo/momos->MOMOS; chai/tea/chaha/chay->TEA; coffee->COFFEE; shake/shakes/mastani->SHAKE; taak/tak/chaas/chhaas/chaach/chhach/buttermilk/mattha/majjige->BUTTERMILK; lassi->LASSI; shira/sheera/shiro->SHEERA; aamras/amras->AAMRAS; shrikhand->SHRIKHAND; chapati/chapathi/chappati/phulka/poli/fulka->CHAPATI; roti->ROTI; bhakri/bhakari/bhakar->BHAKRI; paratha/parotha/parantha/parotta->PARATHA; kulcha->KULCHA; naan/nan->NAAN; bajra/bajri/bajari->BAJRA; jowar/jwari/jowari->JOWAR; nachni/ragi/nagali->RAGI; papad/papadum/papadam/poppadom->PAPAD; pakoda/pakora/bhajiya/bhaji-when-fritter is NOT handled (bhaji stays BHAJI, meaning sabzi); pakoda/pakora/pakode/bhajia/bhajiya->PAKODA; vada/wada->VADA; pitla/pithla/pithale/zunka/jhunka->PITLA (besan is NOT pitla; besan->BESAN); soyabean/soya/soyabeans->SOYA (chaap/chap->CHAAP separate); curd/dahi->CURD; fries/fry-as-noun? NO: "fry"/"fried" -> FRY (cooking style, soft); steamed/steam->STEAM; grilled/grill->GRILL; roasted/roast->ROAST; crispy/crunchy/kurkure->CRISPY; sandwich/sandwiches/sandwhich->SANDWICH; burger/burgers->BURGER; pizza/pizzas->PIZZA; pasta->PASTA; maggi/maggie->MAGGI; noodle/noodles/chowmein/chow mein->NOODLES; brownie->BROWNIE; mojito->MOJITO; thali->THALI; dosa/dosai->DOSA; idli/idly->IDLI; uttapam/uthappam->UTTAPAM; samosa->SAMOSA; kachori->KACHORI; paneer->PANEER; corn/corns/sweetcorn->CORN.
4. NOISE (removed from tokens): size/qty/serving/marketing words: small, medium, large, regular, reg, jumbo? (NO: jumbo stays, it is visual-ish soft), half, full, quarter, qtr, plate, plates, pcs, pc, piece, pieces, nos, no, ml, ltr, litre, liter, gm, gms, gram, grams, kg, inch, inches, serves, portion, special, spl, spcl, house, chef, chefs, signature, classic, the, of, with, and, in, a, an, on, n, style, fresh, new, hot? (NO: keep hot for drinks as soft), veg (handled as diet hint, then removed), vegetarian, jain (diet hint, then removed), non, nonveg, shree, shri, sri, desi, homemade, delicious, tasty, famous, best, premium, combo? (NO: combos detected separately), numbers (any token that is all digits), single letters. "Plate" alone as the only remaining token must not empty the query: if removing noise empties the token list, fall back to the non-noise-filtered tokens.
5. NON_VISUAL (kept as tokens but ignored when deciding tier; never required to match): dum, adrak, ginger, tulsi, elaichi, cardamom, irani, indori, mumbai, punjabi? (NO: punjabi changes nothing visible -> nonvisual yes), hyderabadi (nonvisual), lucknowi, kolhapuri? (NO, kolhapuri is a visibly red curry style -> soft), spicy, mild, masaledar, special, amritsari, desi, homestyle, dhaba, authentic, mast, tasty.
   SOFT (may be missing for a "close" match, never for exact/strong): PERIPERI, masala, FRY, CRISPY, dry, gravy, sukha, rassa, kolhapuri, TANDOORI? (NO: tandoori changes colour -> visual), hot, cold? (NO), CHILLI? (NO, chilli paneer is a distinct dish -> visual), jumbo, mini, double, extra, loaded.
   Everything else = visual (must match).
6. HEADS: canonical token -> head (dish type). Include at least: PIZZA, BURGER, SANDWICH, PASTA, MAGGI(head MAGGI), NOODLES, FRIEDRICE, MOMOS, FRIES, GARLICBREAD, SHAKE, COLDCOFFEE, COFFEE, TEA, MOJITO, LASSI, BUTTERMILK, ICECREAM, BROWNIE, CAKE, BIRYANI, PULAO, RICE, THALI, DOSA, IDLI, UTTAPAM, VADAPAV, PAVBHAJI, MISAL, SAMOSA, KACHORI, PAKODA, VADA, PAPAD, MASALAPAPAD(head PAPAD), CHAPATI, ROTI, BHAKRI, PARATHA, KULCHA, NAAN, DAL, CURD, SHEERA, SHRIKHAND, AAMRAS, GULABJAMUN, SPRINGROLL, ROLL (roll/wrap/frankie/kathi->ROLL), SALAD, SOUP, OMELETTE (omelette/omlette/omlet->OMELETTE), BHURJI, KHICHDI, SABUDANAKHICHDI, DALKHICHDI, WAFFLE, PANCAKE, JUICE, SODA, LEMONADE (nimbu pani/lemonade/shikanji->LEMONADE), KEBAB (kebab/kabab/kabob->KEBAB), TIKKA, CHAAP, BUNMASKA, SIZZLER, NACHOS, TACO, WRAP->ROLL, HANDI, CURRY (curry->CURRY). Rule: `parse_dish(...).head` = the head of the LAST head-token in the main variant (English order puts the dish type last: "Paneer Tikka Pizza" -> PIZZA, "Pizza Style Sandwich" -> SANDWICH). Multiple heads joined by combo words handled in step 9.
   HEAD_GROUP: head -> visual group, groups: "drink_glass" (SHAKE, COLDCOFFEE, MOJITO, LASSI, BUTTERMILK, JUICE, SODA, LEMONADE), "hot_cup" (TEA, COFFEE), "dessert" (ICECREAM, BROWNIE, CAKE, SHEERA, SHRIKHAND, GULABJAMUN, AAMRAS, WAFFLE, PANCAKE), "flatbread" (CHAPATI, ROTI, BHAKRI, PARATHA, KULCHA, NAAN), "rice" (BIRYANI, PULAO, RICE, FRIEDRICE, KHICHDI, DALKHICHDI, SABUDANAKHICHDI), "curry" (CURRY, DAL, HANDI, MISAL, PAVBHAJI), "bread_snack" (SANDWICH, GARLICBREAD, BUNMASKA, VADAPAV, BURGER), "pizza" (PIZZA), "noodle_pasta" (PASTA, MAGGI, NOODLES), "fried_snack" (FRIES, PAKODA, VADA, SAMOSA, KACHORI, SPRINGROLL, NACHOS, PAPAD), "south" (DOSA, IDLI, UTTAPAM), "dumpling" (MOMOS), "egg" (OMELETTE, BHURJI), "grill" (KEBAB, TIKKA, CHAAP, SIZZLER), "plate" (THALI), "bowl" (SALAD, SOUP, CURD), "roll" (ROLL, TACO).
   HEAD_PROMPT: head -> short English CLIP prompt ("a pizza", "a milkshake in a tall glass", "an Indian curry in a bowl", ...), one per head.
   HEAD_CUISINES: head -> Zomato cuisine slugs to crawl, e.g. PIZZA:("pizza","italian","fast-food"), SHAKE:("shake","beverages","desserts","ice-cream"), MISAL:("maharashtrian","street-food"), MOMOS:("momos","tibetan","chinese"), BIRYANI:("biryani","mughlai","hyderabadi"), DOSA:("south-indian",), CURRY:("north-indian","maharashtrian"), ... cover every head; unknown -> ("north-indian","street-food","fast-food") is the caller's default.
7. PROTEINS: token -> protein: CHICKEN, MUTTON, FISH, PRAWN, EGG, KEEMA->MUTTON? (NO: keema alone is ambiguous: map KEEMA to protein "KEEMA"), crab->CRAB, pomfret/surmai/bangda/bombil->FISH. NONVEG_PROTEINS = all of them. `item_proteins(name)` returns the protein set from tokens. Paneer, soya, mushroom are NOT proteins (they are "base" role).
8. Diet for `parse_dish`: "nonveg" if any protein except EGG, or category/name contains DIET_HINTS_NONVEG (non veg, nonveg, non-veg, chicken, mutton, seafood, fish); "egg" if EGG is the only protein or name has "egg"/"anda"/"omelette"/BOILEDEGG/BHURJI-with-egg; "veg" if category or name contains DIET_HINTS_VEG ("veg", "jain", "pure veg", "paneer", "vegetarian") and no protein; otherwise "unknown". (A plain "Dal Fry" -> "unknown"; the matcher treats unknown as "veg preferred".)
9. Combos and aliases in `parse_dish(name, category, description)`:
   - display = name with whitespace collapsed.
   - base_key = size_base_key(name): normalize, drop a trailing size/portion part: `\s*[-–(]?\s*(small|medium|large|regular|half|full|quarter|mini|jumbo|single|double)\s*\)?\s*$` (repeat until no change), and trailing quantities like "(250 ml)", "- 2 pcs". "Cheese Pizza - Small" and "Cheese Pizza - Large" share base_key; "Mutton Handi (Full)" and "(Half)" share.
   - variants: parenthetical text is an alias when it has >= 2 non-noise tokens OR contains a head/protein token ("Nagali Papad (Ragi Papad)" -> {RAGI,PAPAD} and main {RAGI,PAPAD} since nagali->RAGI; "Dum Murgh (Dum Chicken)" -> main {dum,CHICKEN}; "Shevga Masala Lal (Drumstick Curry)" -> main and alias {SHEVGA,CURRY}); otherwise its tokens are appended to the main variant as modifiers ("Steam Momos (Veg/Paneer)" -> main {STEAM,MOMOS} plus alias {STEAM,MOMOS,PANEER}; "Baingan Bhaji (Kala Masala Special)" -> main {BAINGAN,BHAJI,kala,masala}). variants[0] is always the main (name outside parentheses) variant.
   - is_combo: `is_combo_name(name)` true when the normalized name contains a COMBO_WORDS token (combo, meal, platter, bucket, thali? (NO thali is a dish), "plus", "with fries", "with coke", "and" joining two HEAD tokens) or " & " / "+" joining two segments that each contain a head ("Cheese Pizza (Half) & Veg Cheese Corn Pizza (Half)" -> combo; "Paneer & Corn Cheese Burger" -> NOT combo because only one head).
   - head as in step 6; for a combo, head = head of the first segment.
10. `item_head(name, category, menu_name)`: head from the item name tokens (last head token); if none, from `category` then `menu_name` using CATEGORY_HEAD_HINTS on normalized text (e.g. "pizzas", "pizza mania", "classic pizzas veg" -> PIZZA; "burgers" -> BURGER; "shakes", "thick shakes", "milkshakes" -> SHAKE; "momos" -> MOMOS; "biryani" -> BIRYANI; "breads", "rotis", "indian breads" -> None? (ambiguous: return "BREADS"? NO: return None); "beverages" -> None; "desserts" -> None; "rice" -> RICE; "sandwiches" -> SANDWICH; "pasta" -> PASTA; "dosa" -> DOSA; "soups" -> SOUP; "salads" -> SALAD; "rolls"/"wraps" -> ROLL; "fries" -> FRIES; "tea"/"chai" -> TEA; "coffee" -> COFFEE; "mocktails"/"mojito" -> MOJITO; "lassi" -> LASSI; "ice cream" -> ICECREAM; "cakes" -> CAKE). Example that MUST hold: item_head("Peri Peri Chicken", "Pizzas") == "PIZZA".
11. `token_role(t)`: "head" if in HEADS, "protein" if in PROTEINS, "nonvisual" if in NON_VISUAL, "soft" if in SOFT, "base" if in {PANEER, SOYA, CHAAP, MUSHROOM, ALOO, GOBI, CORN, MATAR, PALAK, BHINDI, BAINGAN, METHI, CHANA, DAL, RAJMA, KAJU, SEV, SHEVGA, RAGI, BAJRA, JOWAR, BESAN, PITLA, MATKI}, else "visual".
