# T05: Pool store (SQLite) — items, uploads cache, embeddings cache, bad images
Wave: 5 · Deps: T01, T04 · Risk: med · Model: sonnet

## Goal
`studio/store.py` persists every restaurant menu ever fetched (so the photo pool grows across jobs), the upload cache (image sha256 -> hosted URL), image embeddings, and known-bad image URLs, in one thread-safe SQLite file; it imports the shipped seed pool once.

## Read first
- `studio/models.py` (PoolItem, RestaurantMenu)
- `studio/zomato.py` (canonical_res_url, city_of, chain_key)
- `.orchestrator/PLAN.md` Contracts -> studio/store.py (seed line format)

## Write-set
- create: studio/store.py
- test: tests/test_store.py

## Contracts
- Produces: `class PoolStore` exactly as in PLAN (`__init__(self, path: Path)`, `ensure_seeded(self, seed_path: Path) -> int`, `upsert_menu(self, menu: RestaurantMenu) -> int`, `menu_fetched_at(self, res_url: str) -> float | None`, `all_items(self) -> list[PoolItem]`, `items_for_restaurant(self, res_url: str) -> list[PoolItem]`, `count_items(self) -> int`, `count_restaurants(self) -> int`, `get_upload(self, sha256: str) -> str | None`, `put_upload(self, sha256: str, url: str, host: str) -> None`, `get_embedding(self, key: str) -> numpy.ndarray | None`, `put_embedding(self, key: str, vec: numpy.ndarray) -> None`, `mark_bad_image(self, img_url: str, reason: str) -> None`, `is_bad_image(self, img_url: str) -> bool`), plus `close(self) -> None`.
- Seed JSONL (gzip, utf-8, one JSON object per line): `{"r": res_url, "rn": res_name, "c": city, "n": name, "cat": category, "m": menu_name, "d": description, "dt": diet, "i": img_url}`.

## Steps
1. Open `sqlite3.connect(str(path), check_same_thread=False, timeout=30)`; `PRAGMA journal_mode=WAL`, `PRAGMA synchronous=NORMAL`; parent dir created. All public methods hold one `threading.RLock`.
2. Schema (create if not exists):
   - `meta(k TEXT PRIMARY KEY, v TEXT)`
   - `restaurants(res_url TEXT PRIMARY KEY, res_id TEXT, name TEXT, city TEXT, cuisines TEXT, chain_key TEXT, fetched_at REAL, source TEXT)` (source "seed" | "live")
   - `items(item_id INTEGER PRIMARY KEY AUTOINCREMENT, res_url TEXT, name TEXT, category TEXT, menu_name TEXT, description TEXT, diet TEXT, img_url TEXT)` + index on res_url + index on img_url
   - `uploads(sha256 TEXT PRIMARY KEY, url TEXT, host TEXT, created_at REAL)`
   - `embeddings(k TEXT PRIMARY KEY, dim INTEGER, vec BLOB)` (float32 bytes)
   - `bad_images(img_url TEXT PRIMARY KEY, reason TEXT, at REAL)`
3. `upsert_menu(menu)`: in one transaction: upsert the restaurant row (fetched_at = time.time(), source "live"), delete its items, insert menu.items; return inserted count. Empty item list still records the restaurant (so it is not re-fetched immediately).
4. `ensure_seeded(seed_path)`: if meta "seed_sig" equals f"{size}:{mtime_ns}" of seed_path -> return 0. Missing seed file -> return 0 (log info). Else stream the gzip lines; group by "r"; for restaurants NOT already present with source "live", insert restaurant (source "seed", fetched_at = 0) and items (batch executemany, 5000 rows per batch); skip malformed lines; store seed_sig; return number of items inserted. Must handle 400k lines in under ~60 s.
5. `all_items()`: join items with restaurants -> PoolItem(item_id, name, category, menu_name, description, diet, img_url, res_id, res_name=restaurants.name, res_url, city, chain_key). Cache the list in memory; invalidate the cache on upsert_menu/ensure_seeded writes.
6. Embeddings: `put_embedding(key, vec)` stores `np.asarray(vec, dtype=np.float32).tobytes()` and dim; `get_embedding` returns a float32 array or None.
7. `menu_fetched_at(res_url)` uses canonical_res_url; returns fetched_at (0.0 for seed rows) or None if unknown.

## Test cases
- TC1 upsert_menu then all_items returns PoolItems with every field set (res_name, city, chain_key from the restaurant row); count_items/count_restaurants correct.
- TC2 upsert_menu twice for the same restaurant replaces items (no duplicates) and updates fetched_at.
- TC3 ensure_seeded imports a 3-restaurant gzip JSONL built in tmp_path, returns item count; a second call returns 0; a malformed line is skipped; a restaurant already stored as "live" is not overwritten by the seed.
- TC4 uploads: get_upload unknown -> None; put then get returns url.
- TC5 embeddings round-trip a float32 vector of dim 512 exactly (np.array_equal).
- TC6 bad images: mark then is_bad_image True; unknown False.
- TC7 unicode item names/descriptions round-trip.
- TC8 thread-safety: 4 threads each upsert 25 menus concurrently -> count_restaurants == 100, no exception.
- TC9 reopening the same path (new PoolStore) sees previous data.
