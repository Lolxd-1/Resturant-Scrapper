# T09: SmartBiz output builder (READY, PENDING, REPORT)
Wave: 9 · Deps: T01 · Risk: med · Model: sonnet

## Goal
`studio/sheets.py` turns the per-dish results into three files: an upload-ready SmartBiz sheet (menu categories in column H), a PENDING SmartBiz sheet for everything not ready, and a human-readable REPORT workbook with an owner photo checklist.

## Context
Bug being fixed: v1 `build_sheet` (zomato_scrapper.py lines 534-587) wrote "Other Food and Grocery" into column H for every row, so the SmartBiz app showed a single category. Template facts (column numbers, limits, sheet names) are in `.orchestrator/recon/findings.md` "SmartBiz template facts". The template sheet `bulk_upload_template` has ~49,000 pre-formatted validation rows: never iterate to max_row, never delete rows.

## Contracts
- Produces: `build_outputs(results: list[DishResult], template: Path, out_dir: Path, vendor: str) -> dict[str, Path]` with keys "ready", "pending", "report"; `safe_vendor(vendor: str) -> str` (letters/digits/underscore, collapsed, max 40, fallback "Vendor"); file names `f"{safe_vendor(vendor)}_SmartBiz_UPLOAD_READY.xlsx"`, `..._SmartBiz_PENDING.xlsx`, `..._Photo_Report.xlsx`.

## Steps
1. Sort results by `row`. READY = status "ready" (hosted_url set and price > 0). PENDING = everything else.
2. READY and PENDING files: `shutil.copyfile(template, dest)`, open with openpyxl (NOT read_only), sheet "bulk_upload_template", write rows contiguously starting at row 2:
   C = sku; D = name[:200]; E = price (int when it is a whole number, else round 2); F = same as E; G = "FOOD_AND_GROCERY"; H = category_for(result)[:100]; I = description[:2000] (or None when empty); P = hosted_url (or None).
   For PENDING rows with price None, leave E and F empty.
   `category_for(r)`: r.category if non-blank, else "Menu". (Inference for blank categories is done upstream in the pipeline; here only guarantee non-empty.)
   Save, close.
3. REPORT (new openpyxl Workbook, NOT the template):
   - Sheet "Summary": rows of label/value: Vendor, Generated (local time "%d %b %Y %H:%M"), Dishes in menu, Ready to upload, Need owner photo, Need price, Errors, Photo coverage (ready+needs_price-with-photo / total, as percent with 0 decimals), Visual check ("On"/"Unavailable" — read from a module-level optional arg: add parameter `vision_on: bool = True` as a keyword-only argument with default True to build_outputs; this is the only allowed extension of the contract).
   - Sheet "Dishes": header [SKU, Dish, Category, Price, Status, Reason, Confidence, Match, Source, Zomato item, Restaurant, Restaurant link, Photo link]; one row per result; Status shown as friendly text: ready->"Ready", needs_photo->"Needs owner photo", needs_price->"Needs price", error->"Error"; Confidence as integer percent; links as hyperlinks (cell.hyperlink) with the URL text; bold header, frozen header row, auto-filter, column widths set (Dish 38, Reason 40, links 30, others 12-18).
   - Sheet "Owner photo checklist": header [SKU, Dish, Category, Why, How to shoot]; rows for status needs_photo; Why = r.reason; How to shoot = "Top-down or 45° shot in daylight, dish centred on a plain plate, no text or logos, at least 800x800 px."
4. All strings written as-is (unicode safe). Remove characters illegal in XML (openpyxl `ILLEGAL_CHARACTERS_RE`) from every string before writing.
5. `out_dir` is created if missing. Return the three paths.

## Test cases

- TC4 limits: name of 250 chars -> D length 200; description 3000 chars -> I length 2000; category 150 chars -> H length 100.
- TC5 template intact: READY workbook still has sheets ["important_instructions","bulk_upload_template","DataSheet"] in that order, header row 1 unchanged (compare to the template's row 1 values), DataSheet still hidden.

- TC7 report: "Dishes" has one row per result with friendly status; "Owner photo checklist" lists only needs_photo rows; Summary coverage percent correct for a known mix.
- TC8 speed: 150 results build all three files in < 20 s using `data/smartbiz_template.xlsx`.
- TC9 prices: 120.0 written as int 120; 99.5 stays 99.5.
