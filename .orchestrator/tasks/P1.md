# P1: Swiggy search breadth-first by rung + option-rung marker
Wave: 6 · Deps: A5 · Risk: med · Model: sonnet

## Goal
Every unresolved dish gets its exact-name Swiggy search before any dish spends requests on look-alike names, so long menus are fully covered within the request cap. Groups also record which rung is "the same dish without its bracketed option" for the AI judge (B3).

## Context (evidence from the live eval 2026-10-07)
`_Run._swiggy_search` (studio/pipeline.py) walks group by group and, inside each group, rung 0..2 in 2 cities each (up to 6 requests per dish), stopping all Swiggy work at 300 requests. On a 226-dish menu the cap was spent on the first ~third of dishes; later dishes that Swiggy has (e.g. "Kaju Lababdar") ended "Not found". Look-alike names are generic ("Chicken Pizza", "Veg Thali") and return plenty of photos from one city.

## Steps
1. Constant `SWIGGY_MAX_REQUESTS = 600` (module level, replaces the 300 literal).
2. `_swiggy_search(groups)` becomes breadth-first: for rung index i in 0, 1, 2: the groups still "open" that have a rung i; query that rung's `_query_text(raw)` in 2 cities when i == 0, else only the first city (same city list and per-(text, city) cache as today); after the pass, re-rank those groups (`ranked_group`) and close a group when rung 0 is confident or it has an exact/strong candidate with rung <= i. Keep the SwiggyBlocked handling, cancel checks, and progress via `self.stage("search", ...)` (progress = requests done / planned, capped at 1.0).
3. `_Group.option_rung: int | None`: index in `self.rungs` of the rung whose `base_key` equals `size_base_key(<dish name with bracketed text removed>)`, when the dish name has brackets and such a rung exists; else None. Set where rungs are built in `read()`.

## Test cases
- TC1 breadth-first: 3 dishes, each with rung 0 and a look-alike rung, none found anywhere; with SWIGGY_MAX_REQUESTS monkeypatched to 3 the 3 Swiggy requests are the 3 rung-0 names (check FakeSession calls' "str" params).
- TC2 cities: with an unlimited cap, a dish whose rung 0 misses and whose rung 1 is searched -> rung-0 query sent for 2 cities, rung-1 query for 1 city.
- TC3 option_rung: dish "Paneer Chilli Sandwich (with Mayo)" -> its group's option_rung is the index of the "Paneer Chilli Sandwich" rung; "Paneer Pizza" (no brackets) -> None.
- TC4 all existing tests pass unchanged (A5 Swiggy tests included).
