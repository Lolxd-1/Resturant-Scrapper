## Goal
`studio/menu.py` reads any reasonable vendor menu file into `MenuParseResult` without ever blocking the run for row-level problems (blank prices, messy categories, duplicates), and derives SKU prefixes.

## Contracts
- Consumes: `MenuRow`, `MenuParseResult` (studio/models.py).
- Produces: `read_menu(path: Path) -> MenuParseResult`, `parse_price(value: object) -> float | None`, `clean_category(text: str) -> str`, `derive_sku_prefix(vendor: str) -> str`.

## Steps
1. `parse_price(value)`: int/float -> float (<= 0 or NaN -> None); str -> strip, remove `₹`, `Rs`, `Rs.`, `INR`, `/-`, commas and spaces (case-insensitive), then take the FIRST number matching `\d+(?:\.\d+)?` (so "100/180" -> 100.0, "Rs. 120/-" -> 120.0, "120.50" -> 120.5); no number or result <= 0 -> None; None/"" -> None. Return whole numbers as float (120.0).
2. `clean_category(text)`: str(text or ""), collapse all whitespace to single spaces, strip, strip surrounding punctuation `-:|*`; if the result is all upper or all lower case and contains letters -> `.title()` but keep words of <= 3 letters that were ALL CAPS in the source as caps only when the source was mixed case (i.e. simply: all-upper/all-lower -> title(); mixed -> unchanged); truncate to 100 chars; return "" for empty.
3. `derive_sku_prefix(vendor)`: words = `re.findall(r"[A-Za-z0-9]+(?:'[A-Za-z]+)?", vendor)`; none -> "SKU"; one word -> first 3 alnum chars upper; else first letter of the first 3 words upper. Strip non A-Z0-9, max 6 chars, fallback "SKU". Examples: "H-Food Cafe"->"HFC", "Domino's"->"DOM", "Shivraj Biryani House"->"SBH", "  "->"SKU", "7 Heaven"->"7H".
4. `read_menu(path)`:
   - Extension check (lowercase): `.xls` -> result with errors=["Please save the file as .xlsx (Excel Workbook) and upload again."]; `.csv` -> read with `csv` module (try utf-8-sig, then cp1252); `.xlsx`/`.xlsm` -> openpyxl `load_workbook(path, data_only=True, read_only=True)`; anything else -> errors=["Unsupported file type <ext>. Upload an .xlsx file."]. Unreadable/corrupt file -> errors=["Could not open the file: <short reason>"]. Never raise.
   - Sheet choice (xlsx): for each worksheet, read the first 2000 rows as lists; pick the sheet whose detected header yields the most dish rows (ties -> first sheet). Record `sheet_name`.
   - Header detection: scan the first 15 rows; a cell matches a role by its normalized text (lowercase, non-letters -> space, stripped) using these synonyms (first match wins per cell, each role taken once, left to right):
     name: "item name","item","dish","dish name","name","product","product name","menu item","particulars"
     category: "category","section","type","menu category","group","course"
     description: "description","desc","details","item description","about"
     price: "price","rate","mrp","amount","cost","selling price","price rs","price inr","rs"
     A row is the header when it has a name role AND (price or category) role. If no header found: assume column 0=name, and if the first non-empty row's column 3 parses as a price or column 1 is text, use the v1 layout name=0, category=1, description=2, price=3 with header_row=0 and warning "No header row found; assumed columns Item Name | Category | Description | Price.". `columns` holds the 0-based indexes found.
   - Rows after the header: skip rows whose name cell is empty/whitespace. Name = str(cell).strip() with internal whitespace collapsed; numeric names like 101.0 become "101".
   - Category-header rows: a row with a name, NO parseable price, EMPTY description and EMPTY category, where the NEXT non-empty row has a parseable price, is a section header: set current_category = clean_category(name) and do not emit it as a dish.
   - Category for a dish = clean_category(category cell) if non-empty, else the current section category, else the last non-empty dish category above it (inherit), else "".
   - Price: parse_price(cell); None -> row warning "Price missing or invalid (<raw>)".
   - Description: str(cell or "").strip(), whitespace collapsed.
   - Duplicate names (case-insensitive, same category): keep both; add warning "Duplicate dish name" to the second.
   - `row` numbers are 1..n in order of emitted dishes; `excel_row` is the physical row.
   - Name longer than 200 chars: keep, add warning "Name longer than 200 characters; it will be cut".
   - After parsing: no dishes -> errors=["No dishes found. Row 1 should be: Item Name | Category | Description | Price."]. File-level warnings: count of rows with missing prices ("N dishes have no price; they will be listed in the PENDING sheet.") and when no category column exists ("No Category column; categories will be inferred from dish names.").
5. Tests in tests/test_menu.py covering every test case below; build files with `make_xlsx` in `tmp_path`; CSV via writing text with encoding utf-8-sig.
